# 飲食店スタッフ スキル管理アプリ

飲食店のスタッフが「どの仕事を、どこまでできるか」を一覧で管理できる、スタッフスキル管理アプリです。

現在は Java のコンソールアプリとして、最低限の機能を実装しています。今後 Spring Boot と SQL を使って Web アプリ化する予定です。

## 作った理由

私自身が飲食店でアルバイトをしていて、社員の方が「新人スタッフが何を知っていて、何ができるのか」を把握しづらそうにしている場面を何度も見てきました。

- 新人に誰が仕事を教えればいいか分からない
- シフトを組むときに、そのポジションを任せられる人がすぐに分からない
- スタッフのスキルの記録が紙や記憶に頼っていて、更新されない

スタッフごとのできる仕事と習熟度を登録して一覧で確認できれば、こうした課題を解決できると考え、このアプリを企画・開発しています。

## 想定ユーザー

飲食店の社員（スタッフの教育やシフト作成を担当する人）

## 主な機能

| 機能 | 内容 |
|---|---|
| スタッフ登録・一覧 | 名前、メインポジション、入店日を登録して一覧表示 |
| 仕事登録・一覧 | 仕事名とポジションを登録し、ポジションごとにまとめて表示 |
| スキル登録・変更 | スタッフと仕事を選んで習熟度を登録・変更・削除 |
| 仕事からできる人を探す | 仕事を選ぶと、指定した習熟度以上のスタッフを習熟度の高い順に表示 |
| スキルマップ | スタッフ × 仕事の一覧表で、全員の習熟度をひと目で確認 |
| データの保存 | 登録・変更のたびに CSV ファイルへ保存し、次回起動時に読み込み |

ポジションは、実際の勤務先に合わせて「ドリンク、フリー、デシャップ、入口、8階」の5つにしています。

習熟度は次の3段階です。スキルを登録していない状態を「未経験」として扱います。

| 習熟度 | 意味 |
|---|---|
| 1 | 教わった（見守りがあればできる） |
| 2 | 1人でできる |
| 3 | 人に教えられる |

## 実行画面

### スキルマップ

```text
【スキルマップ:全て】
名前  カクテル作成  ビール注ぎ  料理の受け渡し  案内
田中  3             2           -               -
佐藤  2             -           3               -
鈴木  -             1           -               -
(3:教えられる 2:1人でできる 1:教わった -:未経験)
```

### 仕事からできる人を探す

```text
【ドリンク/カクテル作成が1人でできる以上の人】
  田中(メイン:ドリンク):教えられる(更新日:2026-10-02)
  佐藤(メイン:デシャップ):1人でできる(更新日:2026-10-02)
```

### スタッフごとのスキル

```text
【田中さんのスキル】
  ドリンク/カクテル作成:教えられる(更新日:2026-10-02)
  ドリンク/ビール注ぎ:1人でできる(更新日:2026-10-02)
```

## 使用技術

- Java（JDK 25 で動作確認）
- Java 標準ライブラリのみ使用（外部ライブラリなし）
- データ保存：CSV ファイル
- バージョン管理：Git / GitHub

## 動かし方

JDK がインストールされている環境で、次のコマンドを実行します。

```bash
git clone https://github.com/mizukishinano-wq/staff-skill-app.git
cd staff-skill-app
javac -encoding UTF-8 *.java
java StaffSkillApp
```

起動するとメニューが表示されるので、番号を入力して操作します。

```text
1/スタッフ登録 2/スタッフ一覧 3/仕事登録 4/仕事一覧 5/スキル登録・変更 6/仕事からできる人を探す 7/スキルマップ 0/終了>
```

データは同じフォルダの `staffs.csv`、`tasks.csv`、`skills.csv` に保存されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `StaffSkillApp.java` | メニュー、各機能の処理、CSV の保存と読み込み |
| `Staff.java` | スタッフのデータ（番号、名前、メインポジション、入店日） |
| `Task.java` | 仕事のデータ（番号、仕事名、ポジション） |
| `Skill.java` | スキルのデータ（スタッフ番号、仕事番号、習熟度、更新日） |
| `Position.java` | ポジションの一覧 |

## 工夫した点

### データを「スタッフ」「仕事」「スキル」の3つに分けた

スキルは「スタッフ1番が、仕事3番を、習熟度2でできる」のように、名前ではなく番号で記録しています。仕事名を変更してもスキル側を直す必要がなく、今後データベースに移行するときも、そのままテーブル同士の関係として使える形にしました。

### 「仕事からできる人」を探せるようにした

スタッフごとのスキル一覧だけでなく、仕事からできる人を逆に探せるようにしました。シフトを組むときに「このポジションを1人で任せられるのは誰か」をすぐに調べられます。

### 未経験は「登録しない」ことで表した

習熟度を「未経験」に戻すとスキルのデータを削除します。データが無駄に増えず、検索のときも登録されているスキルだけを見ればよくなります。

### 入力ミスでアプリが止まらないようにした

数字以外や範囲外の番号、形式が違う日付を入力しても、エラーで終了せずに入力し直しを求めます。また、CSV が壊れないように、名前や仕事名に「,」を使えないようにしています。

### 日本語でも表の列がそろうようにした

ターミナルでは漢字やカタカナなどの全角文字が半角文字の2文字分の幅になるため、通常の `printf` では列がずれてしまいます。文字ごとの表示幅を計算して空白で埋める処理を作り、スキルマップの列をそろえました。

### 個人情報を公開しないようにした

実際に使うとスタッフの名前が CSV に保存されるため、`.gitignore` で CSV ファイルを GitHub に上げないようにしています。
